# S2-58 設計

案 B を採用する。既存の SceneChanged は UUID が期待と一致すると自動操作として計画を適用するため、案 A では同じシーンを選ぶ人の意図を区別できない。
補助接続で program を直接変更し、成功後、中核ループ内で人の切替入力を処理する。期待、履歴、待機の持ち主を解除し、後続の OBS イベントは既存の規則で処理する。OBS/IRL Link の既存経路は変えない。同じシーンを選んだ場合も解除する。
要求は中核ループで直列処理する。補助接続の各要求は既存の2秒期限に従う。この間、中核のイベント処理は待つ。
Studio Mode でも preview ではなく program を直接変更する。

| 状態 | HTTP | code | 日本語 | 英語 |
| --- | --- | --- | --- | --- |
| 未接続・期限切れ | 503 | api.disconnected | OBS に接続されていません | OBS is disconnected |
| 未知 UUID | 404 | api.scene_missing | シーンが見つかりません | Scene not found |
| 切替失敗 | 502 | api.scene_failed | シーンの切替に失敗しました | Scene switch failed |
| 不正な本文 | 400 | api.invalid | 既存の文 | 既存の文 |

画面は全シーンを OBS の順序で取得し、大きいボタンにする。現在のシーンには文字と aria-pressed を付ける。送信中は一覧を無効化し、SSE の現在 UUID が一致したら解除する。失敗、切断、確認期限切れでも解除して再試行できる。

## spec 追記案
屋外からのシーン操作は補助接続の SetCurrentProgramScene に UUID を渡し、Studio Mode でも program を直接切り替える。成功時は中核へ明示的な人の切替入力を渡す。期待と同じ UUID でも待機の持ち主・履歴・期待を解除する。POST の本文は scene_uuid。GET は uuid/name の配列。認証と独自 CSRF ヘッダーを必須とする。応答は上表に従う。
