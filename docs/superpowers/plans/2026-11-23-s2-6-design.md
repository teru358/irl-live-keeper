# S2-6 設計

- `(*App).Restart() error` は容量1の要求チャネルへ送り、HTTP の要求終了や世代停止を待たず戻る。実行役だけが停止と作成を直列に行う。
- 受付と同時に `applying / restart`、作成成功で `applied / restart`、失敗で `failed / restart` と理由を公開する。反映中の重複は `ErrApplying`。実行前・終了中・終了後は `ErrNotRunning`。
- 失敗では世代を残さず、全 OS のコンソールで理由を標準エラーへ出し終了コード1。GUI の待機は S2-17・S2-18。
- 秘密の集合（管理・送信・読み取り・OBS・MediaMTX API）、表示済みの印、apply、成功版ハッシュは App に保持する。新しい logger に旧秘密も渡す。InitJob は App 準備時の1回だけ。
- 起動表示は最初に表示した世代だけ。再作成では表示しない。
- 停止中のシグナルは停止完了後に確認し、次を作らず終了する。作成中のシグナルでは作成を完了（失敗なら回収）してから停止する。途中の部品を残さない。終了受付を閉じる操作と再起動受付は同じ mutex で守る。
- spec への追記案: 「再起動受付は要求処理を待たず戻り、実行役が直列に停止・再作成する。停止中の終了合図では再作成せず、作成中なら完了後に回収する。旧 MediaMTX API パスワードもプロセス終了まで伏字対象に残す。」
