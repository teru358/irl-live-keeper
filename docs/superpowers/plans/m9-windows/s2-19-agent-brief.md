# S2-19 区切り1の実機の確認（小さな窓、二重の起動、管理ページ、スマホ。Windows の Claude Code 向けの指示書）

あなたは、irl-live-keeper（以下「本体」）の第2段階・区切り1の実機の確認を、ユーザーと一緒に進める。この指示書のフォルダ（`s2-19`。以下「確認のフォルダ」）で作業する。**ユーザーへの文は日本語で書く。** 目で見ること（窓や画面の見た目、スマホの操作）と、config.yaml の書き換え、Windows の設定の変更はユーザーに頼む。それ以外（起動の確認、プロセスとポートの確認、ログの読み取り、記録）はあなたが行う。

## 新しい本体について（今までの版との違い）

- **`irl-live-keeper.exe` は GUI の版**: コンソールの窓を出さず、小さな窓で動く。ログはファイル（`logs\`）にだけ書く。今までのようにコンソールで動かすには `irl-live-keeper.exe --cli`（自分のコンソールの窓が開く）
- **ログは英語だけ**になった（例: 「MediaMTX が終了しました」→ `MediaMTX exited unexpectedly`、`止める操作を受けました` → `Shutdown requested`）。`camera changed` などは今までどおり
- **管理ページができた**: `http://127.0.0.1:<admin.port>/`（既定 8787）。状態（スマホは下のタブ: 回線・シーン・操作）、シーンの切り替え、送信の設定（URL の各部分のコピーと QR）、ログ、日本語 / English、自動 / ライト / ダーク
- 本体の status の文（`watch-status.ps1 -Once` の warnings など）は、言語の指定がないと、本体の言語（config の `language`。既定 `auto` で OS の言語）になる
- config.yaml に新しい項目 `language`（既定 `auto`）と `gui.close_action`（既定 `confirm`）がある。書いていなければ既定として読む

## 前提・守ること

- 今までの確認と同じ: パスワードを画面への出力・記録・ユーザーへの文に書かない。`config.yaml` と `ws-password.txt` を表示しない。**あなたは config.yaml を書き換えない**（書き換えはユーザーに頼む）。止めてよいプロセスは、あなたが起動したものだけ（PID で）。本体と OBS はユーザーが起動・終了する。シーンコレクションを切り替えない
- 試験の配信先を使う項目はない（配信は始めない。シーンの切り替えは配信していなくても試せる）
- **本体の入れ替え**: ユーザーに、今の本体を終了してから、確認のフォルダの `irl-live-keeper.exe` を、今の本体のフォルダ（config.yaml のあるフォルダ）の exe と入れ替えてもらう（元の exe は別の名前で残してもらう）。`ctl.exe` も同じ
- 迷ったら、進めずにユーザーに聞く

## 確かめること

項目ごとに、ユーザーの言葉、ログの行（`logs\` の今日のファイルの新しい行）、あなたの判断を記録する。スクリーンショットはユーザーに頼み（`Win + Shift + S`）、確認のフォルダに `項目番号-説明.png` で保存してもらう。
