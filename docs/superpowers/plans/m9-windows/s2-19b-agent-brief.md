# S2-19 の確かめ直し（直した所だけ。Windows の Claude Code 向けの指示書）

前回の S2-19（`../s2-19/s2-19-agent-brief.md` と `s2-19-result.md`）の続き。**前提・守ることは前回の指示書のとおり**（パスワードを書かない、config.yaml はあなたは書き換えない、止めてよいのは自分が起動したものだけ〔PID で〕、本体と OBS はユーザーが起動・終了する）。ユーザーへの文は日本語。

ユーザーに、本体を終了してから、このフォルダ（`s2-19b`）の `irl-live-keeper.exe` を本体のフォルダの exe と入れ替えてもらう（`ctl.exe` は前回のままでよい）。

## 確かめること

| # | 手順 | 確かめること |
|---|---|---|
| R-1 窓のボタン | 本体を起動してもらう。窓のボタンを、マウスと、Tab と Enter で押してもらう | **4つのボタンが反応すること**（前回は反応しなかった）。Tab で選択の枠が移ること。題名の帯の左上のアイコンが A3 になっていること。回線の行が「メインカメラ (main)」のように出るか、kbps に桁の区切り（`2,450`）、DOWN のとき空のかっこ `()` が出ないこと |
| R-2 管理ページを開く（K-5） | 窓の「管理ページを開く」 | ブラウザで、ログインを通らずに状態の画面が出ること |
| R-3 終了とブラウザ（K-8） | R-2 のブラウザを残したまま、窓の「終了」→ 確認で「はい」 | ブラウザが残ること。本体と MediaMTX が残っていないこと。**`logs\crash-*.log` が、終了のときに消えていること**（前回は次の起動まで残った） |
| R-4 起動の失敗（K-9） | `powershell -ExecutionPolicy Bypass -File .\occupy-ports.ps1 -Target rtmp` を裏で起動（PID を控える）してから、本体を起動してもらう | 窓が残り、見出しが「起動できませんでした」で、ポートの文が「ほかのプログラム（前回の irl-live-keeper や mediamtx など）が…」になっていること。**「ログを開く」でエクスプローラーが開くこと。** スクリプトを PID で止めてから「もう一度試す」→ 本体が動き出すこと |
| R-5 `--cli` の Ctrl+C（K-11） | PowerShell から `.\irl-live-keeper.exe --cli`。動き出したら、開いたコンソールの窓で Ctrl+C | 窓がすぐ閉じずに、`Shutdown requested` と `shutdown complete` の行が出てから閉じること（ログのファイルにも）。MediaMTX が残らないこと。もう一度 `--cli` で起動し、今度はコンソールの窓の「×」で閉じる → ログのファイルに同じ2行があること |
| R-6 再起動のログ | 本体が動いている状態で、管理ページか API から再起動（前回の K-10 のとおり。PowerShell 7 なら `-Authentication Basic -AllowUnencryptedAuthentication` を足す） | ログに `restart requested` と `restart complete` が出ること |
| R-7 二重の起動のログ | 窓を最小化して、もう一度 exe をダブルクリック | 前の窓が前に出ること。ログに `second instance blocked` が出ること |
| R-8 管理ページの直し | 管理ページ（PC とスマホ） | OBS につながったあと、「OBS に未接続」が消えること（スマホでも、下のバーに隠れない所に出る）。言語の切り替えで、選んだほうに印が付くこと。送信の設定で住所を替えても、画面がずれないこと。**送り先の住所の候補に、`172.17.…` や `172.31.…` などの仮のアドレスが出ないこと**（LAN と Tailscale だけ） |
| R-9 管理ページのログ | 管理ページからシーンを切り替える、ログアウトして入り直す | ログに `scene selected from admin page`、`admin logout`、`admin login` が出ること（パスワードや合言葉は出ない） |

## 記録

このフォルダに `s2-19b-result.md` を作り、項目ごとに、ユーザーの言葉、ログの行、あなたの判断を書く。ユーザーに、できたことを伝える。
