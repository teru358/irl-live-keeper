# S2-33 の確かめ直し 3回目（S2-33b で残った所だけ。chrome-devtools-mcp を使う。Windows の Claude Code 向けの指示書）

前回（`../s2-33b/s2-33b-agent-brief.md` と `s2-33b-result.md`）の続き。**前提・守ることと「devtools で守ること」は前回の指示書のとおり**（パスワードと URL を書かない、config.yaml を直接書き換えない、「表示」〔今回から目玉のアイコン〕を押さない、送信の設定の画面は写しも読み取りもしない、通信の中身を読まない、操作のたびにコンソールの誤りを見る、止めてよいのは自分が起動したものだけ）。ユーザーへの文は日本語。手順は画面に出る名前で書いてある。

前回の指示書の誤りを直した: 「シーン別の逃がし先」は「OBS」の区分にある。「スマホで開く」の住所は、今回から選択の欄になった。

## 始める前に

1. `list_pages` で devtools が使えるか確かめる
2. ユーザーに本体を終了してもらい、このフォルダ（`s2-33c`）の `irl-live-keeper.exe` を本体のフォルダの exe と入れ替えてもらう。本体と OBS を起動してもらう
3. devtools で管理ページを開き、ログインの画面が出たら、ユーザーに devtools の Chrome でログインしてもらう
