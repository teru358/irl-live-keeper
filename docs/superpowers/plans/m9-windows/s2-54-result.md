1. X-6 の「一覧のカードの URL（`/source/link-test`）」: 実際のカードの URL は `http://<LAN の番地>:8787/source/link-test`（admin.lan がオンのため LAN の番地）。番地の部分が指示書にない
2. X-9 の「プレビューと OBS の画面に赤い背景が出る」: 先に OBS にソースを足していると、保存しただけでは OBS に出ない。OBS でキャッシュの更新をする手順が要る（または X-9 を X-6 より前にする）
3. X-10 の「3つとも文字が出る」: 新しく作ったソースは既定の文字色が黒で、OBS の黒い画面では見えない。「中身は短くてよい」だけでなく、色を白にする手順か、既定の色の前提が要る
4. X-2 の「途中で `{link.` まで打ったときに補完の候補が出るか見る」と X-11 の「補完の候補が出ている途中で変換してみる」: 候補は `{` のあとに1文字打たないと出ない。X-11 には、候補を出す打ち方を書くとよい
5. X-9 の「差し込みのボタンが入れる形でよい」: ボタンは `url("…")` だけを入れ、カーソルが無ければいちばん前に入る。`background-image:` は自分で書く必要がある
6. X-1 は「窓を見てもらう」だけで、写しの撮り方がない。ユーザーは撮れなかった
7. X-8 の配信の手順で、`ctl.exe test setup` を行うと OBS のシーンが T-B に変わる。ブラウザソースを足したシーン（Camera）が見えなくなる点が書いていない
