# S2-82 区切り5（整理）の実機の確かめ（chrome-devtools-mcp を使う。Windows の Claude Code 向けの指示書）

前回（`../s2-54c/s2-54c-agent-brief.md` と `s2-54c-result.md`）の続き。**前提・守ることは `../s2-33b/s2-33b-agent-brief.md` の「devtools で守ること」のとおり**（パスワードと URL のパスワードの部分を書かない、config.yaml を直接書き換えない、「表示」〔目玉のアイコン〕を押さない、通信の中身を読まない、操作のたびにコンソールの誤りを見る、止めてよいのは自分が起動したものだけ〔PID で〕）。ユーザーへの文は日本語。手順は画面に出る名前で書いてある（「」の中が画面の文字）。前提の状態は決めつけず、今の値を見てから進める。**LAN の番地は記録しない**（写しを撮る前に、番地が出ている欄の文字を「<LAN の番地>」に置き換える）。devtools のツールは `pageId` が要る。

## この版で変わったこと（2026-11-27〜28 のユーザーの決め。spec v0.31）

- **メニュー**は「状態」「カメラ」「ソース」「設定」。「送信の設定」「配信の記録」「ログ」はない
- **カメラ**のページ: 上に共通の欄（自動切替、しきい値、RTMP / SRT を受け付ける、送信のアプリ名・ホスト・ポート）。カメラのカードは番号の順（「カメラ 1（名前）」）。カードの中に「送り先」（畳んである）と「このカメラの送信用パスワードを作り直す」。カメラの id は `cam1`〜`cam8` で、「追加」で空いている一番小さい番号が付き、変えられない
- **送信用のユーザー名とパスワードはカメラごと**（ユーザー名はカメラの id。読み取り用〔OBS〕は今までどおり1組）
- 「カメラ」と「設定」は**別々に保存**する。保存していない変更があるとメニューに「未保存」が出る。ページを移っても下書きは残り、管理ページを閉じる・読み直すときだけ確かめが出る
- 「直前の保存を取り消す」でも、パスワード（管理・読み取り・カメラごとの送信用）は戻らない
- **ソース**は「HTML 本文」を1つのエディターで書く（`<style>` と HTML と `{cam1.kbps}` などの差し込み）。装飾の欄と自由な CSS の欄はない。「新しく作る」で「ひな形」（文字だけ / 縁取り / 背景つき / 状態で色が変わる）を選ぶ。値の名前は `cam1.kbps` など（前の `camera.*` はない）
- OBS のページは、**見た目（CSS）や素材の差し替えも、開いたまま届く**（OBS のキャッシュの更新は要らない）
- 「回線の状況のテスト」は「回線」「待機」「配信」の3つの選び方（どれにも「実際」）と「自由」
- 素材は、本体のフォルダの `source-files` に**エクスプローラーで直接入れても**使える。エディターへのドラッグ＆ドロップでも取り込める

## devtools で追加で守ること

- **カメラのカードの「送り先」を開いた状態では、写しも読み取り（take_snapshot、本文の読み取り）もしない**（URL とパスワードが文字で出る）。送り先の確かめはユーザーに頼む。開いたら確かめのあとすぐ畳む
- 「送り先の住所」の選ぶ欄に LAN の番地が出る。写しの前に置き換える

## 始める前に（ユーザーの手作業が要る）

1. `list_pages` で devtools が使えるか確かめる
2. ユーザーに本体と OBS を終了してもらう。あなたが `config.yaml` を `config.yaml.before-s2-82` に、`sources.yaml` があれば `sources.yaml.before-s2-82` に写す（中身は表示しない）。**`sources.yaml` は前の形なので、写したあと元の `sources.yaml` は名前を `sources.yaml.old-s2-82` に替えて退避する**（新しい本体は前の形を読めない。中身は表示しない）
3. **ユーザーに config.yaml を手で直してもらう**（あなたは書き換えない。ユーザーにメモ帳などで次をしてもらう）:
   - `cameras:` の下の各カメラの `id:` を、上から順に `cam1`、`cam2`…に変える（今 `main`、`sub` なら `cam1`、`cam2`）
   - `stream:` の下の `publish_user:` と `publish_pass:` の2行を消す
   - 各カメラの `id:` の行のすぐ下（同じ字下げ）に `publish_pass: ` と、仮の英数字 24 文字を書く（例の形: `publish_pass: TempTempTempTempTemp0001`。カメラごとに違う文字で。あとで画面から作り直す）
   - 直し終えたら保存してもらう。あなたは「直しましたか」と聞くだけで、中身は見ない
4. このフォルダ（`s2-82`）の `irl-live-keeper.exe` を本体のフォルダの exe と入れ替えてもらう。`ctl.exe` もこのフォルダのものを使う（前のものは古いカメラの id を使う）
5. 本体を起動してもらう。窓に誤りが出たら、理由の文（パスワードの部分を除く）を記録して、ユーザーと一緒に config.yaml の直しを見直す（あなたは中身を見ない。ユーザーに読んでもらう）
6. OBS を起動してもらう。devtools で管理ページを開き、ログインの画面が出たらユーザーにログインしてもらう
