## 指示書の誤り

1. **参照先の場所**: 「前提・守ることは `../s2-33b/s2-33b-agent-brief.md`」とあるが、ファイルは `trash\s2-33b\s2-33b-agent-brief.md` に移っていた
2. **F-3 の自動切替**: 自動切替は配信中だけ動く（配信の開始で切り替わり、停止で戻る）。配信していないときは、回線を悪くしても待機シーンに移らない。「配信中に」の条件と、試験の配信先の用意（F-9 と同じ）を書く必要がある
3. **F-1 / F-2 の作り直しのボタンの場所**: 「カードの中に…「このカメラの送信用パスワードを作り直す」」とあるが、ボタンは「送り先」の中にある。「送り先」を開くと読み取り禁止になるため、devtools では畳んだままスクリプトで押した。押し方を書いておくとよい
4. **F-4 の8台の確かめ**: 同じ下書きで削除と追加をしたあとに続けると、7台で「この下書きで使える番号がありません。…」になり、「カメラは8台までです。」は出ない。8台を確かめる前に「読み直す」を入れる必要がある
5. **F-6 の取り消しの対象**: 取り消しは全体で一番新しい保存に効く。F-5 の最後に保存日数を戻して保存すると、F-6 で戻るのは「保存日数」になり、F-2 の変更は戻らない。順番か、戻る項目の見込みを書く必要がある
6. **F-8 の `@keyframes` の例**: 本文の末尾に足すと、F-7 の大きな画像のうしろに出て OBS の枠の外になる。また、文字の色の指定がないと、OBS の黒い背景で見えない。先頭に置き、色を指定する例にするとよい
7. **F-8 の画像の差し替え**: 元の画像の控えを `source-files` の中に置くと、素材として出てくる。控えは別のフォルダに置くよう書くとよい
8. **ドロップに使う画像**: 手元の画像には、画面の写し（ブラウザのタブやブックマーク）が入りやすい。写しに残るので、中身の決まった試験用の png を用意しておくとよい
