## 指示書の誤り

1. G-8: DELETE の結果を 404 としているが、本文が `sky.png` を参照したまま送ると 409 になる。参照を消して保存したあとなら 404。手順の順番（DELETE → 本文から消す）を入れ替えるか、期待する番号を 409 にする必要がある
2. G-8: 「素材の欄を開き直して snapshot」とあるが、「一覧へ戻る」→「編集」で開き直しても `Sky.png` は出ない。ページの読み直しが要る
3. 始める前に: `ctl.exe` を動かすには `OBS_WS_ADDR` と `OBS_WS_PASSWORD_FILE` の指定が要る。指定しないと `FAIL password: open : The system cannot find the file specified.` になる（前回の指示書にはあった）
4. G-3: 「「設定」に「本体を再起動する」がある」とあるが、「カメラ」にもある。誤りではないが、「カメラ」にも残ることを書いておくと確かめやすい
