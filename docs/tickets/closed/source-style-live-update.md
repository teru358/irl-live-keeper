# [source-style-live-update] ソースの見た目の保存を、開いている OBS へ自動で届ける

**状態**: 是正済 / **優先**: 中 / **種別**: 機能

## 現象

ソースの装飾・自由な CSS・素材を保存しても、すでに開いている OBS のブラウザソースには届かない（source.js は SSE で文字だけを差し替える）。OBS のプロパティで「現在のページのキャッシュを更新」を押すまで古い見た目のまま（S2-54 の X-9、X-10）。当面は管理ページに案内を出す（2026-11-27 のユーザーの裁定）。案: SSE で見た目の版を送り、source.js が style.css を版つきの URL で読み直す（spec 第9節・6章を直す）

## 修正内容

- 2026-11-28: spec v0.28 でソースを HTML の本文にし、CSS も本文と一緒に SSE で届く形にした（S2-78、9d6dfde 以降）。見た目の保存も開いている OBS に届く。同じ名前の素材の差し替えも ?v= で届く（S2-85）。試しの本体と Chromium で確かめた
