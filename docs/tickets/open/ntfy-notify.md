# [ntfy-notify] ntfy で回線の悪化と待機の切り替えをスマホに知らせる（検討）

**状態**: 設計待ち / **優先**: 低 / **種別**: 機能

## 現象

スマホの管理ページはバックグラウンドで止まり（iOS Safari はすぐ、Android Chrome は数分）、http:// のページなので Web Push も使えない。屋外配信中に、配信アプリを前に出したまま回線の悪化や待機への切り替えを知る手段がない。2026-11-24 のユーザーの問い。案: 本体が ntfy（iOS・Android の通知アプリ。HTTP で1行送るとスマホに届く）の宛先へ短い文を送る。知らせるのは「待機へ切り替えた・戻した・カメラが LOW / DOWN になった」など。外へ送る文にパスワード・URL を入れない。宛先（topic の名前）は推測されにくい名前にし、秘密として扱う（ログに出さない）。ntfy.sh か自前の ntfy の server を選べるように。気をつける点: 送っているスマホ自身の回線が悪いので、完全に切れたら通知もつながり直すまで届かない（LOW の知らせに向く）。コアの spec は「Discord / Twitch 連携」を作らないものにしているので、入れるなら新しい機能としてユーザーの決めと spec の追加が要る。段階（区切り3のあと、第3段階など）は未定
