# [unused-camera-display] 今のコレクションにメディアソースがないカメラを、警告でなく「使っていない」と出す（検討）

**状態**: 設計待ち / **優先**: 低 / **種別**: 機能

## 現象

カメラ1〜3を設定し、シーンコレクションごとに使うカメラを変える使い方（コレクション1はカメラ1・2、コレクション2はカメラ2・3）は今の作りでできる（メディアソースは URL で見つけ、自動の切替はシーンに映るカメラだけを見る）。ただ、今のコレクションに出てこないカメラについて、status の警告「<カメラ> のメディアソースが見つかりません」（obs.source_missing、internal/obs/mapread.go の cameraWarnings）と、窓・管理ページの回線の行の DOWN が出続ける。案: 今のコレクションにメディアソースがないカメラは、回線の行に「このコレクションでは使っていない」と薄く出し、警告にしない。ただしメディアソースの消し忘れと見分けられなくなるので、つないだときに1回だけ知らせる、などを決める。ntfy の通知（ntfy-notify）を入れるときも、使っていないカメラは知らせない。プロファイルの切替は、本体がプロファイルの中身を使わないので対応不要（2026-11-25 のユーザーの判断）
